// why it exists

Your downtime is
wasted build time.

Every night there's an eight-hour window where nothing ships. You're asleep, and so is your project. Night Shift was built to close that gap. It turns the hours you're offline into real, reviewable progress.

The idea is simple. You drop a short list of tasks into a shared file before bed. A coordinated crew of agents executes them inside Roblox Studio while you rest. No babysitting. No prompts at 3am. The work happens on its own.

The best part isn't the speed. It's the wake-up moment. You make coffee, open the changelog, and a feature that didn't exist last night is built and tested. That loop is addictive in the best way. It compounds night after night.

// the night cycle

One loop, start to sunrise.

Each run follows the same six beats. You only touch the first and the last. The crew owns everything in between.

01 · QUEUE

You queue tasks

Before bed, you drop a short list of tasks into the shared mission file. That's your whole job.

02 · ORCHESTRATE

Orchestrator plans

Orchestrator reads the queue and breaks it into work. It assigns each agent and caps the run at three tasks.

03 · BUILD

The crew executes

Designer, Programmer, and Map Builder act directly inside Roblox Studio. They work through the MCP bridge.

04 · VERIFY

QA tests it

QA runs the build and hunts for bugs. Anything broken gets kicked back to be fixed before morning.

05 · LOG

Archivist records

Every change is written to the changelog. A snapshot is mirrored so the next run has full context.

06 · WAKE

You review

You wake up and open the changelog. You decide what ships and what gets queued for the next shift.

// the crew · 6 agents

Meet the night shift.

A small, specialized roster. Each agent owns one job. They coordinate through a shared markdown brain, so no agent steps on another's work.

ORCHESTRATOR

Product Manager

Perfect Planner

The one who never sleeps. It reads the mission queue and plans the run. Then it assigns every other agent and keeps the shift on task and on budget.

  • Breaks the queue into assignable tasks
  • Enforces the 3-task-per-run cap
  • Resolves conflicts between agents
ENGINEER

Programmer

Gameplay Engineer

Turns specs into working systems. Writes the Luau that powers mechanics, economy, and progression. This is the code that makes the game actually play.

  • Implements mechanics from the design spec
  • Wires up systems and economy hooks
  • Fixes bugs QA sends back
ARCHITECT

Map Builder

World Architect

Builds the space the game lives in. Lays out the world, places props and spawns, and wires the environment together inside Roblox Studio.

  • Constructs layouts and arenas
  • Places spawns, props, and triggers
  • Keeps the scene organized and performant
DESIGNER

Game Designer

Systems & Fun

Decides what's worth building and why it's fun. Defines mechanics, tuning, and reward loops. Then hands a clear spec to the Programmer.

  • Designs mechanics and progression
  • Tunes economy and reward loops
  • Writes specs the crew builds from
TESTER

QA

Quality Assurance

The gatekeeper before morning. Runs the build and verifies systems behave. Bounces anything broken back to the Programmer with a report.

  • Runs and exercises the build
  • Hunts bugs and edge cases
  • Signs off only when it's green
SCRIBE

Archivist

Memory & Records

The crew's memory. Writes the changelog and maintains the shared markdown state. Snapshots the project so every run starts with full context.

  • Writes the morning changelog
  • Maintains shared markdown memory
  • Captures delta-mirror snapshots
// systems

What makes it run.

The crew is the cast. These are the systems underneath that keep an unattended overnight run focused, cheap, and reliable.

Shared Mission Log

Every agent reads and writes the same markdown files. It is one source of truth. The crew stays in sync without stepping on each other.

Roblox Studio MCP Bridge

An MCP integration layer lets agents act directly inside the engine. They edit scripts and the scene like a teammate, instead of pasting code blindly.

Delta-Mirror Snapshots

Only what changed gets synced each run. The state stays fast, cheap, and conflict-free. The next shift picks up cleanly.

3-Task Cap Per Run

A hard limit keeps the crew focused. The output stays reviewable in one sitting. The token cost stays predictable instead of running away.

Overnight Autonomy

Queue it and walk away. The full plan, build, test, and log loop runs with zero supervision from lights-out to sunrise.

Lean v3 Design

Fewer agents and a tighter loop. Snapshot mirroring rebuilt the system around cost. It ships more per token than earlier versions.
